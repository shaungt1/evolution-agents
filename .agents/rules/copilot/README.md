# GitHub Copilot Rules

This folder is reserved for GitHub Copilot's own standing operating rules. Store each rule at `<rule-name>/rules.md` and register it in the [provider rule manifest](../RULES.md).

No Copilot-specific rule is registered yet, and this change does not modify Copilot's configuration. Codex's TOML keys and sandbox flags do not apply to Copilot.
